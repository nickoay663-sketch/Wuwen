# Testimony Protocol

Version: 1.2

## Purpose

This protocol defines how testimony enters Wuwen Honest Runtime.

Every Runtime begins with testimony.

## Input

A testimony may originate from:

- Text
- Image
- Audio
- Video
- Speech
- Document
- Contract
- News Report
- Academic Paper
- AI-generated Content

All inputs are converted into testimony before Runtime begins.

## Runtime Process

Every testimony enters the same Runtime.

Testimony

↓

Recognition

↓

Definition

↓

Search

↓

Evidence

↓

Correspondence

↓

Reasoning

↓

Responsibility

↓

Reconstruction

## Runtime Output

Every Runtime produces:

- Runtime Report
- Runtime Questions
- Reconstructed Expression

Reconstructed expressions may become testimony for the next Runtime.

## Principle

One Runtime.

One Testimony.

One Responsibility.
