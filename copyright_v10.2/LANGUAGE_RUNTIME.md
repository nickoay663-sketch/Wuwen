# Language Runtime v1.1

# 勿问语言运行系统 v1.1


## Purpose

Language Runtime is the first Runtime layer executed by Wuwen.

Its responsibility is not to translate expressions.

Its responsibility is to establish the original language testimony environment before entering Wuwen Runtime.

语言运行系统是勿问执行的第一层运行环境。

它不负责翻译表达。

它负责在进入勿问 Runtime 前，建立表达所属语言的原始证词运行环境。


---

## Principle

Language is not the runtime logic.

Language is the testimony environment.

Expression is not the language itself.

Expression exists inside a language environment.

语言不是运行逻辑。

语言是证词环境。

表达不是语言本身。

表达存在于语言环境之中。


---

## Core Axiom

### Language Environment Principle

Input language defines the testimony environment.

Runtime defines the responsibility structure.

Language may change.

Runtime does not change.


输入语言决定证词运行环境。

Runtime 决定责任运行结构。

语言可以变化。

Runtime 不变化。

## Language Detection

The first task of Language Runtime is identifying the natural language.

Output:

- Language
- Confidence
- Detected Features


语言识别只负责确认表达语言。

不负责判断真假。

不负责修改表达。


---

## Language Environment

Each language keeps its own:

- Grammar
- Concepts
- Cultural context
- Expression structure


每种语言保持自己的：

- 语法结构
- 概念环境
- 文化背景
- 表达方式


Language Runtime preserves the original testimony environment.

语言运行系统保护原始证词环境。


---

## Semantic Layer

Language Runtime creates a structured semantic layer.

It does not replace the original expression.

结构化语义层用于帮助 Runtime 理解表达。

但不替代原始证词。


---

## Independence

Different languages enter the same Wuwen Constitution.

However, each language keeps its original testimony environment.

不同语言进入同一部勿问宪法。

但每种语言保持自己的原始证词环境。
