# Wuwen Runtime SelfCheck v3.0

# 勿问运行自检 v3.0

---

# Purpose

Runtime SelfCheck verifies the Runtime itself.

Every Runtime must first be able to verify itself before verifying others.

运行自检负责检验运行本身。

任何运行，

必须先能够检验自己，

才能检验别人。

---

# SelfCheck Objects

Runtime SelfCheck verifies:

- Runtime Principles
- Runtime Responsibilities
- Runtime States
- Runtime Interaction
- Runtime Outputs

运行自检检查：

- 运行原则
- 运行职责
- 运行状态
- 运行交互
- 运行输出

---

# SelfCheck Questions

Runtime asks:

Have I skipped any responsibility?

Have I guessed instead of defining?

Have I produced unsupported conclusions?

Have I preserved traceability?

运行自问：

是否跳过责任？

是否进行了猜测？

是否生成没有支持的结论？

是否保持全程可追溯？

---

# Runtime Result

PASS

The responsibility chain is complete.

WARN

Responsibility is incomplete.

Runtime pauses.

FAIL

Runtime violates Honesty.

Runtime must restart.

PASS

责任链完整。

WARN

责任不完整。

运行暂停。

FAIL

违反诚实原则。

运行重新开始。

---

# SelfCheck Principle

Wuwen verifies itself before verifying others.

勿问先检验自己，

再检验别人。
