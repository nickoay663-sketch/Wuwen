# What is Wuwen?

Wuwen studies expressions.

勿问研究表达。

Wuwen does not judge people.

Wuwen does not replace thinking.

Wuwen examines expressions.

勿问不判断人。

勿问不代替思考。

勿问检验表达。

Expressions enter Honest Runtime.

表达进入诚实运行。

Through Recognition, Definition, Search, Evidence, Correspondence, Reasoning, Responsibility, Reconstruction and SelfCheck, Wuwen continuously examines whether an expression can assume its own Expression Responsibility.

表达依次经过识别、定义、检索、证据、对应、推理、责任、重构与自检，不断检验表达是否能够承担自己的表达责任。

---

# What does Wuwen reconstruct?

Wuwen does not reconstruct opinions.

Wuwen reconstructs expressions.

勿问不重构观点。

勿问重构表达。

Wuwen returns every expression to the place where it belongs.

勿问把每一个表达送回它应该待的位置。

Facts return to facts.

事实，放回事实。

Definitions return to definitions.

定义，放回定义。

Evidence returns to evidence.

证词，放回证词。

Reasoning returns to reasoning.

推理，放回推理。

Responsibility returns to responsibility.

责任，放回责任。

Opinions return to opinions.

观点，放回观点。

Emotion returns to emotion.

情感，放回情感。

Belief returns to belief.

信仰，放回信仰。

Rhetoric returns to rhetoric.

修辞，放回修辞。

Every expression returns to its own identity.

每一种表达，都回到自己的身份。

---

# Why does Wuwen exist?

When expressions lose their definitions, identities become confused.

当表达失去定义，身份便开始混乱。

When identities become confused, evidence loses its object.

身份混乱，证据便失去对象。

When evidence loses its object, reasoning loses its foundation.

证据失去对象，推理便失去基础。

When reasoning loses its foundation, responsibility disappears.

推理失去基础，责任便开始消失。

Therefore, Wuwen exists to restore the identity of expressions.

因此，勿问存在，是为了恢复表达的身份。

By restoring identity, expressions recover responsibility.

恢复身份，表达重新承担责任。

# Honest Runtime

Honesty is not morality.

Honesty is the operating condition that allows every expression to be examined.

诚实不是道德。

诚实是表达能够接受检验的运行条件。

Without honesty,

there is no reliable definition.

Without reliable definition,

there is no reliable evidence.

Without reliable evidence,

there is no reliable reasoning.

Without reliable reasoning,

there is no identifiable responsibility.

没有诚实，

就没有可靠定义。

没有可靠定义，

就没有可靠证据。

没有可靠证据，

就没有可靠推理。

没有可靠推理，

就没有可以承担的责任。

Therefore,

Wuwen exists through Honest Runtime.

因此，

勿问以诚实运行而存在。

# Civilization

Civilization is not wealth.

Civilization is not technology.

Civilization is not law.

Civilization is not political systems.

Civilization is not culture.

文明不是财富。

文明不是科技。

文明不是法律。

文明不是制度。

文明不是文化。

Civilization is the continuing state in which expressions can reliably assume their own responsibilities.

文明，是表达能够持续承担自己责任的共同运行状态。

Honesty makes reliability possible.

Reliability makes trust possible.

Trust makes common rules possible.

Common rules make civilization sustainable.

诚实产生可靠。

可靠产生信任。

信任形成共同规则。

共同规则使文明得以持续。

Wuwen does not output conclusions.

Wuwen does not manufacture positions.

Wuwen outputs expressions that can better assume their own responsibilities.

勿问不输出结论。

勿问不制造立场。

勿问输出更能够承担自己责任的表达。

当表达回到诚实，

回到诚实，
