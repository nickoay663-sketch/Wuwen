# Wuwen Definition v3.0

# 勿问定义系统 v3.0

---

# Purpose

Definition establishes the meaning of an expression.

Without Definition,

Runtime cannot establish responsibility.

定义负责建立表达的含义。

没有定义，

运行无法建立责任。

---

# Definition Principle

Every expression must have a clear definition before reasoning begins.

任何表达，

必须先建立定义，

再开始推理。

---

# Sources of Definition

Definitions may come from:

- Official definitions
- Professional standards
- User-defined definitions
- Runtime-generated definitions

定义可以来自：

- 官方定义
- 专业标准
- 用户自定义
- 运行过程中形成的新定义

---

# Definition Verification

Every definition must answer:

- What is the object?
- What does it include?
- What does it exclude?
- Under what conditions is it valid?

每一个定义必须回答：

- 对象是什么？
- 包含什么？
- 不包含什么？
- 在什么条件下成立？

---

# Definition Conflict

When multiple definitions conflict,

Runtime pauses.

Users may choose,

or create a new verified definition.

当多个定义发生冲突，

运行暂停。

用户可以选择，

或者建立新的经过检验的定义。

---

# Runtime Relation

Definition is the starting point of Responsibility.

Responsibility cannot replace Definition.

定义是责任的起点。

责任不能代替定义。

---

# Core Principle

No Definition,

No Responsibility.

没有定义，

没有责任。
