# Wuwen Runtime Responsibilities v3.0

# 勿问运行职责 v3.0

---

# Purpose

Runtime Responsibilities explain why each Runtime responsibility exists.

Runtime Responsibilities do not describe implementation.

They describe responsibility.

运行职责说明：

为什么存在每一个运行职责。

运行职责不描述实现。

只描述责任。

---

# Recognition

Purpose:

Recognize the incoming expression.

Responsibility:

Identify the object entering Runtime.

职责：

识别进入运行系统的表达。

---

# Definition

Purpose:

Establish a clear definition.

Responsibility:

Transform expression into definable testimony.

职责：

建立明确的定义。

把表达转化为可定义的证词。

---

# Search

Purpose:

Provide information required by Runtime.

Responsibility:

Support verification.

Search never determines conclusions.

职责：

提供运行所需信息。

支持检验。

检索不产生结论。

---

# Evidence

Purpose:

Collect evidence.

Responsibility:

Determine whether testimony has support.

职责：

收集证据。

判断证词是否具有支持。

---

# Correspondence

Purpose:

Check consistency.

Responsibility:

Verify correspondence between:

- Expression
- Definition
- Evidence
- Object

职责：

检查：

表达、

定义、

证据、

对象

之间是否一致。

---

# Reasoning

Purpose:

Determine whether responsibility can continue.

Responsibility:

Only derive conclusions supported by previous Runtime.

职责：

判断责任是否能够继续建立。

只允许推出前面运行支持的结论。

---

# Responsibility

Purpose:

Determine who bears responsibility.

Responsibility:

Identify the owner of the expression.

职责：

确定责任承担者。

明确表达由谁承担责任。

---

# Reconstruction

Purpose:

Produce a more responsible expression.

Responsibility:

Reconstruct only after responsibility has been established.

职责：

只有责任建立以后，

才允许进行重构。
