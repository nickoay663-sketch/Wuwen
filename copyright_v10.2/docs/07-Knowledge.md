# Purpose

Knowledge provides stable definitions for Honest Runtime.

Knowledge does not generate conclusions.

Knowledge supports Definition.

知识系统为诚实运行提供稳定定义。

知识系统不产生结论。

知识系统支持定义。

- Official Definitions
- Dictionaries
- Professional Knowledge
- User Definitions
- Runtime Definitions

知识可以来自：

- 官方定义
- 词典
- 专业知识
- 用户定义
- 运行过程中形成的新定义

# User Knowledge

Users may create private definitions.

Private definitions never replace official definitions.

用户可以建立自己的定义。

用户定义不会替代正式定义。

---

# Knowledge Evolution

Knowledge grows through Runtime.

Only verified definitions become stable knowledge.

知识通过运行不断成长。

只有经过检验的定义，

才能成为稳定知识。

# Runtime Relation

Knowledge supports Runtime.

Runtime verifies Knowledge.

Neither replaces the other.

知识支持运行。

运行检验知识。

二者互不替代。
