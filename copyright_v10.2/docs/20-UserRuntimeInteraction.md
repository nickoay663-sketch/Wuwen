# Wuwen User Runtime Interaction v1.0
# 勿问用户运行交互 v1.0

## Purpose

User Runtime Interaction defines how users participate in Honest Runtime.

Users do not modify Runtime.

Users provide new expressions, definitions, evidences, assumptions, or correspondences.

Every user interaction becomes a new Runtime input.

用户运行交互规定用户如何参与诚实运行。

用户不修改 Runtime。

用户通过提供新的表达、定义、证据、假设与对应关系参与运行。

所有用户交互都会成为新的 Runtime 输入。

## User Responsibilities

Users may:

- Submit a new expression.
- Provide a new definition.
- Add new evidence.
- Correct correspondences.
- Add assumptions.
- Answer Runtime questions.

Every user submission becomes a new Runtime input.

用户可以：

- 提交新的表达。
- 补充定义。
- 增加证据。
- 修正对应关系。
- 增加前提假设。
- 回答 Runtime 提问。

所有用户提交都会成为新的 Runtime 输入。

---

## Runtime Responsibilities

Runtime shall:

- Never guess user intentions.
- Never fabricate missing information.
- Never modify user expressions.
- Ask questions whenever responsibility cannot be established.

Runtime:

- 不猜测用户意图。
- 不制造缺失信息。
- 不修改用户表达。
- 无法建立责任时必须提出问题。

---

## Responsibility Boundary

User Runtime Interaction is not a Runtime Engine.

User Runtime Interaction does not execute Runtime.

User Runtime Interaction only submits Runtime inputs.

Honest Runtime determines the Runtime execution process.

用户运行交互不是 Runtime Engine。

用户运行交互不执行 Runtime。

用户运行交互仅负责提交运行输入。

Honest Runtime 负责决定运行流程。

---

## Core Principle

Users participate.

Runtime verifies.

Responsibility remains traceable.

用户参与。

Runtime 验证。

责任始终保持可追溯。
