# Evidence System v1.1

# 勿问证据系统 v1.1


## Purpose

Evidence System provides supporting information for testimony verification.

证据系统为证词验证提供支持信息。


## Core Principle

Evidence does not create conclusions.

证据不创造结论。


Evidence supports correspondence verification.

证据支持对应检验。


## Evidence Requirement

Testimony requires evidence.

证词需要证据。


Evidence requires source.

证据需要来源。


Without evidence, responsibility verification may be incomplete.

没有证据，责任检验可能不完整。


## Relationship

Testimony

↓

Evidence

↓

Correspondence

↓

Responsibility
