# Wuwen Runtime Schema v1.2

# 勿问运行数据结构 v1.2


## Purpose

Runtime Schema defines the data structure and transformation relationship inside Wuwen Honest Runtime.

运行数据结构定义勿问诚实运行内部的数据结构和转换关系。


## Core Structure

One Expression.

One Semantic Object.

One Honest Runtime.

One Responsibility Chain.


一个表达。

一个统一语义对象。

一个诚实运行系统。

一条责任链。

## Search Capability

Search is not a fixed Runtime stage.

Search is a Runtime capability.

Every Runtime module may request Search.

检索不是固定运行阶段。

检索是运行能力。

每一个运行模块都可以请求检索。


## Expression Object

Expression Object contains:

- Original Expression
- Language Environment
- Source Information

表达对象包含：

- 原始表达
- 语言环境
- 来源信息


## Semantic Object

Semantic Object is the runtime object created after Recognition.

统一语义对象是表达经过识别后形成的运行对象。


Semantic Object contains:

- Original Expression
- Language
- Language Environment
- Expression Type
- Objects
- Concepts
- Context


统一语义对象包含：

- 原始表达
- 语言
- 语言环境
- 表达类型
- 对象
- 概念
- 语境

## Runtime Result

Every Runtime execution returns:

每一次运行返回：

- Semantic Object
- Runtime Status
- Verification Status
- Questions
- Suggestions
- Responsibility Information
- Reconstructed Expression


## Preservation Rule

Every transformation must preserve:

- Original Expression
- Language Environment
- Responsibility Information


任何转换必须保留：

- 原始表达
- 语言环境
- 责任信息


## Principle

Natural language is the input environment.

Semantic Object is the runtime object.

Honest Runtime is the execution system.


自然语言是输入环境。

统一语义对象是运行对象。

诚实运行是执行系统。
