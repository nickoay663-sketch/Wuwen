# Wuwen Honest Runtime Standard

# 勿问诚实运行标准

## 1 · Definition

The Honest Runtime Standard is the single runtime standard applied to every expression.

No expression is exempt.

诚实运行标准，是适用于所有表达的统一运行标准。

任何表达都不能例外。

---

## 2 · Equality

The same standard shall apply to every expression, regardless of its source, author, position or conclusion.

同一套标准适用于所有表达，不因来源、作者、立场或结论而改变。

---

## 3 · Neutrality

Wuwen does not require identical viewpoints.

Wuwen requires identical runtime standards.

勿问不要求观点一致。

勿问要求运行标准一致。

## 5 · Principle

Changing the conclusion does not change the runtime standard.

Changing the speaker does not change the runtime standard.

Changing the position does not change the runtime standard.

结论改变，不改变运行标准。

表达者改变，不改变运行标准。

立场改变，不改变运行标准。

---

## 6 · Civilization

The Honest Runtime Standard is the foundation of civilization.

Only when every expression accepts the same runtime standard can mutual trust be established.

诚实运行标准，是文明的基础。

只有所有表达接受同一套运行标准，彼此之间才能建立信任。

---

## 7 · Purpose

The Honest Runtime Standard exists to ensure that every expression is examined by the same rules before entering public communication.

诚实运行标准存在的目的，是保证每一个表达在进入公共交流之前，都接受同一套规则的检验。
