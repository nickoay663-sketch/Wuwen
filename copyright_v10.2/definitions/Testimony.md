Version

1.1

Concept

Testimony

Definition

A testimony is any expression made by a person.

It may be spoken, written, recorded, photographed, filmed, or otherwise presented.

Wuwen always starts from testimony.

Runtime Meaning

Testimony is the only Runtime input.

Without testimony,

Runtime does not execute.

Required Conditions

A testimony should:

- Remain unchanged during Runtime execution
- Preserve its original wording
- Be traceable to its provider

Wuwen never rewrites testimony before analysis.

Possible Contents

A testimony may contain:

- Objects
- Concepts
- Claims
- Events
- Relationships

Responsibility

The testimony provider bears responsibility for the testimony.

Wuwen bears responsibility only for executing Runtime honestly.

Runtime Principle

Runtime starts from testimony.

Testimony precedes definition.

Definition precedes reasoning.

证词

版本

1.1

概念

证词

定义

证词，是一个人作出的任何表达。

它可以是口头、文字、录音、照片、视频或其他表达形式。

勿问始终从证词开始运行。

运行意义

证词是勿问运行的唯一输入。

没有证词，

勿问不运行。

所需条件

证词应当：

- 在运行过程中保持不变
- 保留原始表达
- 能够追溯到证词提供者

勿问不会在分析之前修改证词。

可能包含

证词可能包含：

- 对象
- 概念
- 主张
- 事件
- 关系

责任

证词提供者对证词承担责任。

勿问只对诚实运行负责。

运行原则

运行始于证词。

证词先于定义。

定义先于推理。
