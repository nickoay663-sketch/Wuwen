# Wuwen Reconstruction

Version: 1.0

## Purpose

Reconstruction produces a reconstructed expression after the entire Honest Runtime is completed.

Reconstruction never replaces Runtime.

## Runtime Principle

Reconstruction is the final Runtime process.

Reconstruction never reconstructs an expression before Runtime is completed.

## Reconstruction Output

Reconstruction may produce:

Runtime Report

Runtime Questions

Runtime Summary

Reconstructed Expression

## Runtime Rules

Reconstruction never judges.

Reconstruction never determines truth.

Reconstruction never assumes responsibility.

Reconstruction only reconstructs Runtime results.

## Runtime Report

A Runtime Report may contain:

Recognition Report

Definition Report

Search Report

Evidence Report

Correspondence Report

Reasoning Report

Responsibility Report

Runtime Questions

## Principle

Reconstruction improves expression.

The reconstructed expression remains testimony.

Every reconstructed expression may become testimony for the next Runtime.
