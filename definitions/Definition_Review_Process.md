Definition Review Process

Version

1.1

Purpose

Every definition must pass a complete review process before becoming an official Wuwen definition.

A definition is not accepted because it is proposed.

A definition is accepted only after it can be examined.

Review Process

A candidate definition must pass the following stages:

1. Candidate

The proposed concept enters review.

2. Definition

The meaning and scope of the concept must be clearly specified.

3. Scope

The applicable boundaries of the definition must be identified.

4. Reasoning

The relationship between the definition and its possible conclusions must be examined.

5. Counterexample

Possible exceptions and contradictions must be tested.

6. Responsibility

The provider of the definition must bear responsibility for its content.

7. Approved

Only after completing all stages may the definition become an official Wuwen definition.

Runtime Principle

Wuwen does not accept undefined concepts.

Wuwen does not accept unreviewed definitions.

Definitions require examination before entering Runtime.

定义审核流程

版本

1.1

目的

任何定义，在成为勿问正式定义之前，都必须经过完整审核。

定义不能因为被提出而成立。

定义只有经过检验后，才能被接受。

审核流程

候选定义必须经过以下阶段：

1. 候选

提出需要建立的概念。

2. 定义

明确概念的含义与范围。

3. 范围

确定定义适用的边界。

4. 推理

检查该定义能够支持哪些推论。

5. 反例

检查可能存在的例外与矛盾。

6. 责任

定义提供者对定义内容承担责任。

7. 通过

完成全部审核后，定义才能成为勿问正式定义。

运行原则

勿问不接受未经定义的概念。

勿问不接受未经审核的定义。

定义必须经过检验，才能进入运行。
