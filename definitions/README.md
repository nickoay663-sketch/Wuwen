# Wuwen Definitions

Version

1.1

## Purpose

The Wuwen Definition Library stores reviewed definitions used during Runtime execution.

Definitions are not opinions.

Definitions are boundaries that allow honest verification.

---

## Runtime Principle

Without definition,

there is no reasoning.

Definitions establish the meaning of objects and concepts before verification.

---

## Definition Structure

Each official definition should contain:

- Concept
- Definition
- Definition Source
- Scope
- Runtime Meaning
- Evidence
- Correspondence
- Responsibility
- Related Concepts

---

## Review Process

Before entering the Definition Library,

every definition must pass:

Candidate

↓

Definition

↓

Scope

↓

Reasoning

↓

Counterexample

↓

Responsibility

↓

Approved

---

## Library

The Definition Library contains concepts that have passed review and are available for Wuwen Runtime.

---

# 勿问定义库

版本

1.1

## 目的

勿问定义库用于保存经过审核、可用于 Runtime 运行的定义。

定义不是观点。

定义是让诚实验证成为可能的边界。

---

## 运行原则

没有定义，

就没有推理。

定义在验证之前，

确定对象与概念的含义。

---

## 定义结构

每一个正式定义应包含：

- 概念
- 定义
- 定义来源
- 范围
- 运行意义
- 证据
- 对应
- 责任
- 相关概念

---

## 审核流程

任何定义进入定义库之前，

必须经过：

候选

↓

定义

↓

范围

↓

推理

↓

反例

↓

责任

↓

通过

---

## 定义库

定义库保存已经通过审核，

并可供勿问 Runtime 使用的概念定义。
