Concept

Truth

Definition

Truth is a statement that corresponds to reality.

A statement is not true because it is believed.

A statement is not true because it is repeated.

A statement is true only when it corresponds to reality.

Runtime Meaning

Wuwen does not generate truth.

Wuwen verifies whether a statement corresponds to reality through Runtime execution.

Required Evidence

A truth claim should correspond to verifiable evidence.

Evidence should support correspondence with reality.

Responsibility

The testimony provider is responsible for the truth claim.

Wuwen is responsible only for examining whether the claim can be verified.

Runtime Principle

Truth is not determined by authority.

Truth is not determined by repetition.

Truth requires correspondence with reality.

真理

版本

1.1

概念

真理

定义

真理，是与现实相对应的表达。

一句话不会因为被相信而成为真理。

一句话不会因为被重复而成为真理。

只有与现实相对应，表达才能成为真理。

运行意义

勿问不生成真理。

勿问通过运行验证表达是否与现实相对应。

所需证据

真理主张应当对应可验证的证据。

证据应当支持表达与现实之间的对应关系。

责任

证词提供者对真理主张承担责任。

勿问只负责检验表达是否能够被验证。

运行原则

真理不是由权威决定。

真理不是由重复决定。

真理必须与现实对应。
