# Wuwen Runtime Interaction v3.0

# 勿问运行交互 v3.0

---

# Purpose

Runtime Interaction defines how users cooperate with Honest Runtime.

Runtime is not a one-way process.

Users may continuously improve the responsibility chain.

运行交互规定用户如何参与诚实运行。

运行不是单向过程。

用户可以持续完善责任链。

---

# Interaction Principle

Wuwen never guesses.

Wuwen always asks.

Users may modify any responsibility element before Runtime continues.

勿问从不猜测。

勿问始终提问。

用户可以修改任何责任要素，然后继续运行。

---

# User Editable Objects

Users may modify:

- Definition
- Parameters
- Evidence
- Correspondence
- Assumptions

用户可以修改：

- 定义
- 参数
- 证据
- 对应
- 前提条件

---

# Professional Parameters

Professional Runtime may require user-defined parameters.

Examples:

- Interest Rate
- Tax Rate
- Probability
- Physical Constants
- Statistical Assumptions

专业运行允许用户定义参数。

例如：

- 利率
- 税率
- 概率
- 物理常数
- 统计假设

---

# Runtime Restart

Whenever a definition or parameter changes,

Runtime returns to Definition

and rebuilds the responsibility chain.

当定义或参数发生改变，

运行返回定义阶段，

重新建立责任链。

---

# Responsibility Principle

Changing parameters changes responsibility.

Changing responsibility changes reconstruction.

修改参数，

意味着修改责任。

修改责任，

意味着重新重构表达。
