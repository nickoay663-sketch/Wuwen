# Wuwen Runtime States v3.0

# 勿问运行状态 v3.0

---

# Purpose

Runtime States describe the current responsibility state of an expression.

Runtime does not always end with a conclusion.

It always ends with a responsibility state.

运行状态描述一个表达当前所处的责任状态。

运行未必产生结论。

但一定产生责任状态。

---

# State 1

## Responsibility Established

The responsibility chain is complete.

Outputs:

- Responsibility Analysis
- Reconstructed Expression

责任链完整。

输出：

- 责任分析
- 重构表达

---

# State 2

## Responsibility Missing

The responsibility chain cannot continue.

Runtime pauses.

Wuwen requests additional definition, evidence or correspondence.

责任链无法继续。

运行暂停。

勿问请求补充：

- 定义
- 证据
- 对应

---

# State 3

## Responsibility Conflict

Different responsibilities cannot be reconciled.

Runtime returns to the Definition stage.

责任发生冲突。

运行返回定义阶段。

重新建立责任链。

---

# Runtime Principle

Runtime never forces completion.

Responsibility is always more important than completion.

运行绝不为了完成而完成。

责任永远高于完成。
