# Wuwen Universal Expression Model (UEM) v1.0

## 1. Definition

Universal Expression Model (UEM) is a language-independent representation of an expression.

UEM represents the expression itself, not any particular natural language.

It preserves only the structure explicitly carried by the expression and never introduces information not carried by the expression itself.

---

## 2. Core Principle

Language is the carrier of expression.

Expression is the object of Runtime execution.

Therefore:

Natural Language ≠ Runtime Core

Expression → Universal Representation → Runtime

Chinese, English, Spanish, French, German, Italian, Portuguese, and any other natural language are only different carriers of expression.

---

## 3. Responsibility Boundary

UEM does not determine:

- truth
- falsity
- morality
- legality
- guilt
- innocence
- credibility
- evidence sufficiency

UEM only represents what the expression explicitly contains.

UEM must not:

- invent missing information
- infer unstated facts
- strengthen an expression
- weaken an expression
- convert uncertainty into certainty
- convert an expression into evidence
- convert an expression into a conclusion
