# Wuwen Manifesto

互联网连接了世界。

勿问连接了信任。

诚实，是文明开始的地方。

Wuwen is an Honest Runtime.

Wuwen begins with testimony.

Wuwen does not replace human judgment.

Wuwen does not define truth.

Wuwen restores responsibility.

Wuwen asks questions before conclusions.

Trust begins where honesty begins.

Civilization begins where responsibility returns.
