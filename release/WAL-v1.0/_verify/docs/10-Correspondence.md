# Wuwen Correspondence v3.0

# 勿问对应系统 v3.0

---

# Purpose

Correspondence verifies whether all Runtime elements remain consistent.

Correspondence does not create definitions.

Correspondence does not create evidence.

Correspondence checks whether they correspond.

对应系统负责检验运行过程中各要素是否一致。

对应不建立定义。

对应不建立证据。

对应只检查是否一致。

---

# Correspondence Principle

Every conclusion must correspond to:

- Expression
- Definition
- Object
- Evidence
- Reasoning

任何结论，

必须同时对应：

- 表达
- 定义
- 对象
- 证据
- 推理

---

# Correspondence Verification

Runtime checks:

Does the expression match the definition?

Does the definition describe the object?

Does the evidence support the object?

Does the reasoning follow from the evidence?

运行检查：

表达是否符合定义？

定义是否对应对象？

证据是否支持对象？

推理是否来自证据？

---

# Correspondence Failure

If any correspondence fails,

Runtime pauses.

Responsibility cannot continue.

任何一个对应失败，

运行暂停。

责任不能继续建立。

---

# Runtime Relation

Definition establishes meaning.

Evidence provides support.

Correspondence verifies consistency.

Responsibility evaluates the verified result.

定义建立含义。

证据提供支持。

对应检验一致性。

责任评价检验结果。

---

# Core Principle

No Correspondence,

No Responsibility.

没有对应，

没有责任。
