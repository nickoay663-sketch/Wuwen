# Wuwen Search v3.0

# 勿问检索系统 v3.0

---

# Purpose

Search provides information required by Honest Runtime.

Search never produces conclusions.

Search only provides searchable evidence.

检索负责提供诚实运行所需的信息。

检索不产生结论。

检索只提供可供检验的信息。

---

# Search Principle

Every search result is treated as testimony.

Search results must enter Honest Runtime.

所有检索结果，

首先都是证词。

所有检索结果，

必须进入诚实运行。

---

# Search Sources

Search may obtain information from:

- Local Knowledge
- Documents
- User Definitions
- Internet
- Databases
- APIs

检索可以来自：

- 本地知识
- 文档
- 用户定义
- 互联网
- 数据库
- API

---

# Search Responsibility

Search is responsible for:

Finding information.

Search is NOT responsible for:

Determining truth.

Making conclusions.

承担责任：

寻找信息。

不承担责任：

判断真假。

生成结论。

---

# Search Result

Every search result records:

- Source
- Time
- Content
- Status

每条检索结果记录：

- 来源
- 时间
- 内容
- 状态

---

# Runtime Relation

Search supports Runtime.

Runtime verifies Search.

检索支持运行。

运行检验检索。

Search never replaces Runtime.
