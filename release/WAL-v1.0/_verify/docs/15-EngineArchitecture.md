# Wuwen Engine Architecture v3.0

# 勿问运行引擎架构 v3.0

---

# Purpose

Engine Architecture defines how Runtime Principles become executable Engines.

Engine is implementation.

Runtime is responsibility.

运行引擎架构规定：

如何把运行原则变成真正可执行的 Engine。

Engine 属于实现。

Runtime 属于责任。

---

# Engine Principle

One Responsibility

One Engine

Every Engine performs only one responsibility.

一个职责，

一个 Engine。

任何 Engine 只负责一个职责。

# Engine Relation

Engines never replace Runtime.

Engines implement Runtime.

运行引擎不能替代运行原则。

运行引擎负责实现运行原则。

---

# Extensibility

New Engines may be added.

Existing Engine responsibilities must remain unchanged.

允许新增 Engine。

已有 Engine 的职责不得改变。

---

# Core Principle

Runtime decides responsibility.

Engine executes Runtime.

运行决定责任。

Engine 执行运行。
