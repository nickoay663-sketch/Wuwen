Wuwen Capability Architecture Specification

Version: 1.0

Status: Frozen

Principle

勿问不是知识库。

勿问不是搜索引擎。

勿问不是大语言模型。

勿问是证词运行系统（Testimony Runtime）。

Capability Principle

任何能够提供能力的系统，都可以为勿问服务。

包括但不限于：

- 大语言模型（LLM）
- 搜索引擎
- 知识库
- 学术数据库
- 法律数据库
- OCR
- ASR（语音识别）
- 视频分析
- 翻译系统
- 数据库
- 未来出现的任何能力系统

这些系统统称为：

Capability Providers（能力提供者）。

Runtime Principle

Capability Providers 只提供能力。

能力不是结论。

能力不是责任。

能力不是最终运行结果。

任何能力输出，必须进入 Wuwen Runtime。

Unified Runtime

所有能力输出，统一进入以下运行流程：

Testimony

↓

Recognition

↓

Definition

↓

Search

↓

Evidence

↓

Correspondence

↓

Reasoning

↓

Responsibility

↓

Reconstruction

↓

Report

任何能力来源，不得绕过 Runtime。

Replaceability Principle

任何 Capability Provider 都可以增加、更换或删除。

Capability Provider 的变化，不得改变 Wuwen Runtime 的运行原则。

Constitutional Principle

能力可以持续升级。

Runtime 原则保持稳定。

勿问永远不依赖任何单一模型、单一数据库或单一平台。

勿问依赖的是统一的 Runtime。

Final Principle

模型负责提供能力。

勿问负责运行能力。

能力属于外部。

责任属于 Runtime。

这是 Wuwen Runtime 的永久架构原则。
