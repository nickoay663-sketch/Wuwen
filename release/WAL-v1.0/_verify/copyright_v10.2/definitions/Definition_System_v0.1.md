Definition System

Version

1.0

Purpose

Any language-based Runtime must first confirm concepts.

Without definition,

expression cannot establish clear responsibility.

Core Principle

Wuwen begins with definitions.

Wuwen does not assume the meaning of a concept.

Wuwen examines the relationship between:

Definition

↓

Correspondence

↓

Responsibility

Definition Structure

A concept definition contains:

- Name
- Definition Source
- Definition Content
- Scope of Use
- Internal Meaning
- External Boundary
- Possible Responsibility

Definition Sources

A definition may come from:

- Dictionary definition
- Legal definition
- Philosophical definition
- Historical definition
- Sociological definition
- User-defined meaning

Runtime Principle

The same word may have different definitions.

Different definitions may produce different responsibilities.

Therefore:

Wuwen does not automatically select a definition.

Wuwen presents:

Definition

↓

Correspondence

↓

Responsibility

Example

Concept:

Civilization

Possible Definitions:

Dictionary definition

↓

Legal definition

↓

Philosophical definition

↓

Historical definition

↓

Sociological definition

↓

User-defined definition

After the user selects a definition:

Wuwen reruns the responsibility relationship.

Principle

Definition is a boundary.

Boundary determines the range that language can honestly bear.

定义系统

版本

1.0

目的

任何语言运行，

必须先确认概念。

没有定义，

表达就无法建立清晰责任。

核心原则

勿问从定义开始运行。

勿问不预设概念含义。

勿问检验：

定义

↓

对应

↓

责任

定义结构

一个概念包含：

- 名称
- 定义来源
- 定义内容
- 使用范围
- 内涵
- 外延
- 可能承担的责任

定义来源

定义可以来自：

- 词典定义
- 法律定义
- 哲学定义
- 历史定义
- 社会学定义
- 用户自定义

运行原则

同一个词，

可能存在不同定义。

不同定义，

可能产生不同承担。

因此：

勿问不默认选择定义。

勿问展示：

定义

↓

对应

↓

承担

的关系。

示例

概念：

文明

可能定义：

词典定义

↓

法律定义

↓

哲学定义

↓

历史学定义

↓

社会学定义

↓

用户自定义

用户选择后：

勿问重新运行承担关系。

原则

定义是边界。

边界决定语言能够诚实承担的范围。
