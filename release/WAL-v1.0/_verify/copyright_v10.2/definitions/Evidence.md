Concept

Evidence

Definition

Evidence is any verifiable information that can support or contradict testimony.

Evidence does not produce conclusions.

Evidence exists to be examined.

Runtime Meaning

Evidence is collected after testimony has been recognized.

Evidence provides the basis for correspondence.

Runtime examines evidence rather than assuming conclusions.

Required Evidence

Evidence should be:

- Verifiable
- Traceable
- Reproducible

Evidence that cannot be verified is not Runtime evidence.

Responsibility

Evidence itself does not bear responsibility.

Responsibility belongs to the person who provides, selects, interprets, or uses evidence.

Runtime Principle

Evidence is not a conclusion.

Evidence supports verification.

Verification determines correspondence.

证据

版本

1.1

概念

证据

定义

证据，是能够支持或反驳证词的可验证信息。

证据不会产生结论。

证据存在的目的，是接受检验。

运行意义

证据在证词被识别之后进入运行。

证据为对应关系提供基础。

勿问检验证据，而不是假定结论。

所需条件

证据应当具备：

- 可验证
- 可追溯
- 可重复

不能验证的证据，不属于勿问运行中的证据。

责任

证据本身不承担责任。

提供、选择、解释和使用证据的人，应当承担责任。

运行原则

证据不是结论。

证据用于支持验证。

验证决定是否对应。
