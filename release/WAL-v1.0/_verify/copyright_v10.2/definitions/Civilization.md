Concept

Civilization

Definition

Civilization is a state in which expression, behavior, and institutions are able to bear responsibility.

Civilization is not determined by wealth, technology, or power alone.

Civilization requires honesty, responsibility, and verifiable correspondence.

Runtime Meaning

Wuwen does not determine whether civilization exists.

Wuwen examines whether testimony, evidence, correspondence, and reasoning are able to bear responsibility.

Required Conditions

Civilization requires:

- Honest testimony
- Clear definitions
- Verifiable evidence
- Correspondence
- Responsible reasoning

If these conditions cannot be satisfied,

civilization cannot be established through testimony alone.

Responsibility

Every participant bears responsibility for their own testimony.

Wuwen bears responsibility only for honest runtime.

Runtime Principle

Civilization is demonstrated through responsibility.

Responsibility requires verification.

Verification requires honesty.

文明

版本

1.1

概念

文明

定义

文明，是一种表达、行为与制度能够承担责任的状态。

文明并不仅由财富、技术或力量决定。

文明需要诚实、责任，以及能够被验证的对应关系。

运行意义

勿问并不判断文明是否存在。

勿问检验证词、证据、对应与推理是否能够承担责任。

所需条件

文明需要：

- 诚实的证词
- 清晰的定义
- 可验证的证据
- 对应关系
- 能够承担责任的推理

如果这些条件不能满足，

仅凭证词不能建立文明。

责任

每一个参与者，都对自己的证词负责。

勿问只对诚实运行负责。

运行原则

文明体现于责任。

责任依赖验证。

验证建立于诚实。
