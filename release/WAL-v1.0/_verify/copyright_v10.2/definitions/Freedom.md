Version

Concept

Freedom

Definition

Freedom is the ability to make choices without coercion.

Freedom does not mean the absence of responsibility.

Object

Person

Required Evidence

Whether a choice can be refused without coercion.

Whether alternative choices genuinely exist.

Responsibility

Freedom requires responsibility for one's own choices.

Runtime Principle

Freedom is not determined by declaration.

Whether freedom exists should correspond to verifiable evidence.

版本

1.1

概念

自由

定义

自由，是在不受强制的情况下作出选择的能力。

自由并不意味着没有责任。

对象

人

所需证据

是否可以在不受强制的情况下拒绝某种选择。

是否真实存在可供选择的其他方案。

责任

自由意味着对自己的选择承担责任。

运行原则

自由不是一种宣称。

自由是否存在，应当对应可验证的证据。
