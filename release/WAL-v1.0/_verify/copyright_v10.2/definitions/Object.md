Object

Version

1.1

Definition

An object is anything that can be identified, referred to, or examined in testimony.

An object may be a person, thing, organization, event, place, or concept.

Objects are the starting point of Runtime recognition.

Runtime Meaning

Wuwen identifies objects before interpreting testimony.

Without identifiable objects,

Runtime cannot continue reliably.

Requirements

An object should be:

- Identifiable
- Distinguishable
- Referable

Objects should not be confused with conclusions.

Responsibility

The testimony provider bears responsibility for referring to the object correctly.

Wuwen bears responsibility only for recognizing objects consistently.

Runtime Principle

Object recognition is not interpretation.

Recognition determines what is referred to.

Interpretation begins only after recognition.

对象

版本

1.1

定义

对象，是证词中能够被识别、指称或检验的事物。

对象可以是人、事、物、组织、地点、事件或概念。

对象是勿问运行识别阶段的起点。

运行意义

勿问首先识别对象，再解释证词。

如果无法识别对象，

运行就不能可靠地继续。

要求

对象应当具备：

- 可识别
- 可区分
- 可指称

对象不能与结论混淆。

责任

证词提供者应当正确指称对象。

勿问只对一致地识别对象负责。

运行原则

对象识别不是解释。

先识别对象，再进入解释。
