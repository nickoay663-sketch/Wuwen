# Wuwen Evidence v3.0

# 勿问证据系统 v3.0

---

# Purpose

Evidence provides support for testimony.

Evidence does not create responsibility.

Evidence supports responsibility.

证据负责支持证词。

证据不创造责任。

证据支持责任。

---

# Evidence Principle

Every conclusion must be supported by evidence.

Without evidence,

Runtime cannot continue.

任何结论，

必须具有证据支持。

没有证据，

运行不能继续。

---

# Evidence Sources

Evidence may come from:

- Observation
- Documents
- Data
- Experiments
- Testimony
- Search Results

证据可以来自：

- 观察
- 文档
- 数据
- 实验
- 证词
- 检索结果

---

# Evidence Verification

Every piece of evidence records:

- Source
- Time
- Context
- Reliability

每一条证据记录：

- 来源
- 时间
- 上下文
- 可靠性

---

# Evidence Conflict

Conflicting evidence does not automatically produce conclusions.

Runtime returns to verification.

证据冲突，

不会自动产生结论。

运行返回重新检验。

---

# Runtime Relation

Definition explains the object.

Evidence supports the object.

Responsibility evaluates the object.

定义解释对象。

证据支持对象。

责任检验对象。

---

# Core Principle

No Evidence,

No Supported Conclusion.

没有证据，

没有可支持的结论。
