# Search Manager v1.0

## 定义

Search Manager 是勿问诚实运行的统一检索管理器。

Search Manager 不是 Search Engine。

Search Manager 不产生结论。

Search Manager 不参与推理。

Search Manager 唯一职责：

根据 Runtime 的需要提供检索服务。

---

## 服务对象

Search Manager 服务整个 Honest Runtime。

包括：

- Recognition Engine
- Definition Engine
- Evidence Engine
- Correspondence Engine
- Reasoning Engine
- Responsibility Engine
- Reconstruction Engine

任何 Engine 都可以请求 Search Manager。

---

## 检索类型

Search Manager 可以执行：

### 定义检索

建立概念定义。

### 事实检索

建立事实资料。

### 证据检索

寻找能够支持或反驳证词的证据。

### 来源检索

寻找原始出处。

### 缺口检索

发现责任链缺失的位置。

---

## 工作原则

Search Manager：

不判断。

不推理。

不负责。

只负责寻找。

检索结果全部返回 Runtime。

由对应 Engine 使用。

---

## 输出

Search Manager 输出：

- 已找到资料
- 未找到资料
- 检索来源
- 来源数量
- 来源类型
- 检索时间

Search Manager 不输出结论。

---

## 检索失败

如果无法找到足够资料：

返回：

"检索未完成。"

Runtime 可以：

继续等待；

请求用户补充；

或者保留无法回避的问题。
