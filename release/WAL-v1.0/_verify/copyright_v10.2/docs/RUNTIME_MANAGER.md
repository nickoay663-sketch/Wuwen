# Runtime Manager v1.0

## 定义

Runtime Manager 是勿问诚实运行的总调度器。

它不负责识别。

它不负责定义。

它不负责检索。

它不负责推理。

它不负责责任。

它不负责重构。

Runtime Manager 唯一职责：

按照固定顺序调度整个 Honest Runtime。

## 调度原则

Runtime Manager 不参与任何业务判断。

任何判断均由对应 Engine 完成。

Runtime Manager 仅负责：

- 启动运行
- 控制顺序
- 保存运行状态
- 输出最终结果

---

## 运行原则

任何表达必须经过同一条 Runtime Pipeline。

任何 Engine 不得跳过。

任何 Engine 不得改变运行顺序。

任何 Engine 完成后，交由 Runtime Manager 调度下一阶段。
