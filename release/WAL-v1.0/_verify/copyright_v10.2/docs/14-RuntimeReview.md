# Wuwen Runtime Review v3.0

# 勿问运行体系审查 v3.0

---

# Purpose

Runtime Review verifies the integrity of the entire Runtime architecture.

Runtime grows only after successful review.

运行体系审查负责检验整个运行体系是否完整。

只有通过审查，

运行体系才能继续扩展。

---

# Review Objects

Review verifies:

- Runtime Principles
- Runtime Responsibilities
- Runtime States
- Runtime Interaction
- Runtime SelfCheck
- Search
- Knowledge
- Definition
- Evidence
- Correspondence
- Reasoning
- Responsibility
- Reconstruction

---

# Review Questions

Does every document have one responsibility?

Does any responsibility appear twice?

Can Runtime execute from beginning to end?

Can Runtime return to previous stages?

Can Runtime remain honest under uncertainty?

---

# Review Principle

Expansion never comes before verification.

重构先于扩展。

检验先于新增。

---

# Core Principle

A stable Runtime is more valuable than a larger Runtime.

稳定的运行体系，

比更大的运行体系更重要。
