# Runtime Principles

The Runtime does not generate opinions.

The Runtime performs an honest execution.

Every output must be bearable by its own responsibility chain.

No definition.

No reasoning.

The Runtime does not create evidence outside the available evidence chain.

The Runtime does not create conclusions outside the verified responsibility chain.
